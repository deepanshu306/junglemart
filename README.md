# JungleMart

Live: https://junglemart.in

## What it does
E-commerce website for jungle-themed products with product listings and a structured layout.

## Features
- Clean UI sections
- Fast pages & reusable components
- Responsive design

## Tech Stack
- PHP • JS • HTML/CSS • MySQL

## Preview
![Preview](https://api.microlink.io/?url=https%3A%2F%2Fjunglemart.in&screenshot=true&meta=false&embed=screenshot.url)

## Run locally
```bash
# Clone the repo
git clone https://github.com/deepanshu306/junglemart.git
cd junglemart

# Install dependencies (if using Composer/npm for PHP/JS)
# composer install
# npm install

# Serve locally (PHP built-in server)
php -S localhost:8000
```

## Usage
- Navigate through the product categories.
- Browse and view product details.
- Add items to cart and proceed to checkout (if implemented).
